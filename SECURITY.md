# Security

Daylily holds people's journals, so security reports are taken seriously and answered quickly.

## Reporting a vulnerability

Please **don't open a public issue.** Report it privately through GitHub:
[Report a vulnerability](https://github.com/KacemMathlouthi/Daylily/security/advisories/new).

Include what you found, how to reproduce it, and what it lets someone do. You'll hear back within a few days, and
we'll keep you posted until it's fixed. Credit is given in the release notes unless you'd rather stay anonymous.

## What counts

Anything that could expose, change or lose a person's writing, for example:

- reading or writing files outside the journal folder
- content in a page or a file that runs code in the app
- the app loading remote content into its windows
- a way to make the app lose or overwrite words

## Supported versions

Daylily is young; fixes go into the latest release only. Update to the newest version from the
[download page](https://daylily.ink/download).
